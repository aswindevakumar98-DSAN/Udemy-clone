# Udemy-clone

A frontend clone of the **Udemy online learning platform** built using **HTML5 and CSS3**. This project focuses on recreating the layout, styling, navigation, course sections, and responsive user interface of an online learning website.

## 📌 Project Overview

This project is created as a frontend development practice project to improve my understanding of:

* HTML5 structure
* CSS3 styling
* Flexbox
* Responsive layouts
* Navigation bars
* Course cards
* Buttons and UI components
* Page sections and layouts
* Reusable CSS classes

The goal is to recreate the look and feel of an online education platform using only **HTML and CSS**, without JavaScript or backend functionality.
